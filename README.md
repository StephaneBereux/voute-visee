# Visée de la voûte

Page web pour mesurer la forme perçue de la voûte céleste en extérieur : le téléphone sert de pointeur (capteurs d'orientation), on vise le pied d'un repère puis le point du ciel juste au-dessus. La page enregistre l'élévation, la direction, la position GPS, la hauteur du soleil et, si on veut, une photo du ciel.

Ouvrir sur le téléphone : https://stephanebereux.github.io/voute-visee/

Les mesures restent dans le navigateur ; le bouton « Partager les résultats » envoie un fichier JSON et les photos.
