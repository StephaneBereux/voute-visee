# Visée de la voûte

Page web pour mesurer en extérieur la forme perçue de la voûte céleste. Le téléphone sert de pointeur.

1. « Nouveau repère » : photo du repère et du ciel.
2. Viser le pied du repère avec le bord du haut du téléphone, bras tendu : bip.
3. Monter vers le point du ciel juste au-dessus : double bip.
4. Choisir le repère proposé (OpenStreetMap, dans la direction visée) ou le pointer sur la carte.

La page enregistre élévations, direction, position GPS, hauteur du soleil et une estimation des nuages d'après la photo. Hauteur de voûte au-dessus du pied du repère : d × (tan(ciel) − tan(pied)).

Ouvrir sur le téléphone : https://stephanebereux.github.io/voute-visee/
